# Black Russia Macro Bot

Telegram-бот на Python для выдачи текстовых макросов по разделам BlueStacks, MuMu Player и Телефон.

## Возможности
- Обязательная подписка на каналы с проверкой через Telegram Bot API.
- Управление каналами подписки через админ-панель: добавление, редактирование, включение/выключение и удаление.
- Каталог текстовых макросов.
- Отправка длинных макросов в виде `.txt`.
- Добавление, редактирование и удаление макросов через Telegram.
- SQLite хранит пользователей, макросы и каналы.
- Команда `/cancel` отменяет пошаговое действие.

## Установка
Требуется Python 3.11+.

1. Создайте бота через [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Скопируйте `.env.example` в `.env`.
3. В `.env` укажите `BOT_TOKEN` и свой числовой `ADMIN_ID`.
4. Установите зависимости:
   ```bash
   python -m venv .venv
   # Windows:
   .venv\\Scripts\\activate
   # Linux/macOS:
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
5. Добавьте бота в оба обязательных канала и выдайте ему права, позволяющие получать информацию об участниках. Для приватных каналов укажите корректный chat ID и ссылку.
6. Запустите:
   ```bash
   python main.py
   ```

## Администрирование
- `/admin` — открыть панель администратора.
- «Добавить макрос» — выберите `bluestacks`, `mumu` или `phone`, затем заполните поля.
- Для пропуска необязательного поля отправьте `-`.
- «Добавить канал» — укажите название, chat ID или `@username`, затем ссылку `https://t.me/...`.
- «Изменить канал» позволяет менять название, ID/username, ссылку и включать/выключать обязательную подписку.
- `/cancel` — отменить текущий пошаговый ввод.

## Важные замечания
- Бот должен иметь доступ к обоим каналам; иначе проверка подписки может ошибочно не пройти.
- Не публикуйте `.env` и токен.
- На данный момент видео добавляется как HTTPS-ссылка.
- Проверяйте правила игры и платформы перед использованием макросов.
